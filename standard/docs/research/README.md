# Research - insights that feed personas, ideas, and specs

<!-- PDLC-4. The anti-silo home: interviews and studies die in external tools;
     insights belong where the personas and specs they should change live. -->

One file per study from [`_template.md`](_template.md), anonymized hard (the
case-studies rules apply: describe the kind of user, never the person or company).

## The rules

- **An insight that changes nothing is not done** - every study file ends with links:
  which persona it updates, which idea it spawns/parks, which spec it touches. That
  link section is the point; the transcript is not.
- **Personas cite their evidence.** A persona claim challenged in review should trace
  to a study here (or be marked assumption).
- Raw recordings/transcripts stay OUT of the repo (privacy); only the distilled,
  anonymized insight lands.
