# Research - insights that feed personas, ideas, and specs

<!-- PDLC-4. The anti-silo home: interviews and studies die in external tools;
     insights belong where the personas and specs they should change live. -->

One file per study from [`_template.md`](_template.md), **anonymized hard**: describe the
kind of user - "an operations lead at a mid-size logistics firm" - never the person, never
the company, never a quote that identifies either by its details. If a finding cannot be
written without identifying someone, it does not get written. Research earns its place here
by being reusable years later; a study nobody can share is not.

## You have this case - say this

**You just finished talking to users.** The notes are in your head and in a call
recording, which is where they die:

```
> I interviewed five hosts about payouts - write the study, and say what it changes
```

The agent writes the anonymized study and, in the same pass, names what moves: which
persona claim it confirms or breaks, which idea it spawns or parks, which spec it
touches. A study with an empty links section is not finished.

**Someone challenges a persona claim in review.** Either it traces to a study here or
it is an assumption wearing a fact's clothes:

```
> where does "hosts check payouts daily" come from? link the evidence or mark it an assumption
```

**A study contradicts a spec.** Say it plainly rather than filing it away:

```
> the payout study contradicts the notifications spec - open the delta
```

**Corner case - a transcript is not a study.** The recording stays out of the repo
(privacy); what lands is the distilled, anonymized insight and its links.

## The rules

- **An insight that changes nothing is not done** - every study file ends with links:
  which persona it updates, which idea it spawns/parks, which spec it touches. That
  link section is the point; the transcript is not.
- **Personas cite their evidence.** A persona claim challenged in review should trace
  to a study here (or be marked assumption).
- Raw recordings/transcripts stay OUT of the repo (privacy); only the distilled,
  anonymized insight lands.
