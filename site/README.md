# site/ - the product's one web surface (zone 1, never shipped)

| Path | What |
|---|---|
| `index.html` | the landing - hand-authored; quotes `docs/positioning.md` verbatim (site-check enforces it) |
| `docs/` | the docs site - GENERATED by `node tools/docsite.mjs` from the repo's own md, gitignored; never hand-edit |

Deploy = serve this directory (landing at `/`, docs at `/docs/`) after running the
generator; CI builds and checks both on every push.
