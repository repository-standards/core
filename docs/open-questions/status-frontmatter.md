# Spec Status lives in front matter

**Decided:** `in-refinement -> ready-to-develop -> in-development -> live`; the
clarify gate flips readiness mechanically and is the authority - Status is the
human-readable mirror.

**Doubt:** once a tracker mirrors the work, status exists in two places; the
mirror is one-way by design, but humans read both and one will lag.

**A better answer would:** one rendered view that makes the lag invisible, or a
convention for which surface answers "what's the status?" per audience.
