# One source, two surfaces

**Decided:** the human docs site renders from the same md agents read; no
separately authored documentation, ever.

**Doubt:** folder READMEs written for in-place reading may not sequence into a
nextjs.org/docs-style learning path without glue.

**A better answer would:** an IA that reuses the files verbatim and still
teaches in order - or honest evidence that a thin authored overlay is
unavoidable.
