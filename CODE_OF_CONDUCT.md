# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, argue about the work - never about
the person. Challenges to decisions are welcome (that is what
[`docs/open-questions/`](docs/open-questions/README.md) exists for); harassment,
personal attacks and bad-faith derailment are not.

Reports go to **bodurkalukasz@gmail.com**. The maintainer reviews every report
and responds within a week; consequences follow the Covenant's enforcement
guidelines, up to a permanent ban from the project's spaces.
